### 🦪 [akoya-extension](https://github.com/akoya-wallet/akoya-extension)

Chrome extension wallet for PRL. Same addresses as the official Pearl Wallet, keys never leave your
browser, and every line that touches them is public.

- MIT-licensed code, reproducible builds, signed build provenance
- Argon2id + AES-256-GCM vault, offline signing, minimal extension permissions
- Found a vulnerability? Use **private vulnerability reporting** on the repo — never a public issue

> ⚠️ Akoya will **never** ask for your recovery phrase. We are an independent team and are not
> affiliated with Pearl Research Labs.
